# Control de Pagos v5

Proyecto Android de prueba con interfaz azul metalizada y registro local de ingresos, gastos y pagos. El flujo de GitHub Actions produce un APK en **Actions → Compilar APK de prueba → Artifacts**.

**Atención:** no contiene integración real con Firebase, Google Drive, Google Play Billing, ChatGPT ni Gemini. El reconocimiento por voz utiliza el servicio nativo Android si está disponible y requiere revisión manual. Los datos y respaldos son locales y no están cifrados; no usar para información financiera sensible de producción.
